# Smart TV launcher

A fast, ad-free home screen for a Logik 4K Android TV: `launcher/` is the UI, `android/` the app that hosts it.

- **Install / update:** Downloader app, `raw.githubusercontent.com/Oxygn-02/Smart-tv/main/tv.apk`, or Settings > Updates in the launcher.
- **Recovery:** `debloat/RECOVERY.md` (hold Back for 3 seconds at start for safe mode).
- **Build:** `android/README.md`.
- **Restore everything:** `debloat/restore.sh`, or "Switch back on what I switched off" in the launcher.
- **Security:** `SECURITY.md`.
